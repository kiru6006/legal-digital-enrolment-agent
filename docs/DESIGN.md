# AEMS Design System (DESIGN.md)

## 1. Visual Philosophy & Tone
The Advocate Enrolment Management System is an authoritative, statutory legal platform serving the Bar Council of Tamil Nadu and Puducherry. 
- **Tone**: Authoritative, clean, transparent, accessible, and high-efficiency.
- **Affordance**: Compact enterprise UX with high information density, clear visual status hierarchies, and zero confusing clutter.

## 3. UI Component Standards

### 3.1. Height & Sizing Standard
- **Standard Control Height**: All buttons, inputs, search boxes, and dropdown toggles are standardized to **`h-9` (36px)** for desktop consistency.
- **Icon Sizing**: `w-4 h-4` (16px) or `w-4.5 h-4.5` (18px) for buttons; `w-5 h-5` (20px) for prominent navigation icons.

### 3.2. Single-Line Toolbar Rule (`whitespace-nowrap shrink-0`)
- Header menu items, badges, role selectors, and action buttons must never wrap into multi-line text blocks.
- Flex child containers on toolbars must specify `shrink-0 whitespace-nowrap` to prevent browser reflow artifacts on displays between 1024px and 1440px.

### 3.3. Simulated AI Badging Rule
Any data point, discrepancy highlight, or triage score generated by the simulated assistant must carry:
- `SimulatedAiBadge` or a visual label: `SIMULATED AI`
- Explicit disclaimer: *"AI provides assist only. Human officer decision required."*

## 4. Responsive Breakpoints
- **Mobile (< 768px)**: Collapsible sidebar turns into slide-over sheet; main table views switch to compact cards.
- **Tablet (768px – 1024px)**: Standard sidebar collapsed to icon-only mode; dossier view stacks two-column panels vertically.
- **Desktop ($\ge$ 1024px)**: Full dual-panel dossier comparison (original upload on left, extraction & verification on right).
